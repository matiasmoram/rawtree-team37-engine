# `lgbm-cart-v2` training report

**Window:** 2026-11-14 15:30–18:02 UTC. **Dataset:** point-in-time feedback with cart state replayed before each request.

## Data and model

- 27,331 requests / 273,310 shown-item rows; 1,047 clicks and 335 purchases.
- 23,722 requests' items were shown by a team submission; 3,609 by fallback.
- 55,527 cart events replayed; 1,452 catalogue updates replayed; no unknown or duplicate shown items.
- Added four append-only features: item in cart, recency rank in cart, cart age and user cart size. Cart products are candidates at serve time. The prior 41-feature artifacts still load through the feature-prefix compatibility in `ServingModel`.
- Trained click, purchase and factored LightGBM variants. Validation selected click (7 leaves, min leaf 800, L2=1) and purchase (7 leaves, min leaf 200, L2=20); serving choice was factored click × purchase-given-click. Model artifacts are under `models/lgbm_cart_v2_20261114T1802*`.

## Result and decision

The last 25% temporal holdout contained 6,833 requests and 81 purchases. The factored model reached purchase AUC 0.904, but its purchase NDCG was **0.0445 below logged order**; request bootstrap 95% CI `[-0.1065, +0.0152]`. The interval includes zero and the point estimate is negative. This is not evidence to promote the model. The validation slice also selected hyperparameters, so these numbers are diagnostics and somewhat optimistic.

Cart features received meaningful gain in the final models (`cart_age_hours` 7.39% in purchase; `cart_rank` 3.31%; `log_user_cart_n` 3.63%). Keep the artifact registered as `lgbm-cart-v2` for replay and a later challenger, but do not add it to the current live split. The current live comparison requested by the team is only `cf-rot` versus `t37-m4`.

## Next gate

Use an untouched chronological test window and compare paired purchase ranking within requests, split by model/cohort where attribution is exact. Then use a fixed live window with disjoint writer ownership. Do not promote from AUC or feature importance alone.
